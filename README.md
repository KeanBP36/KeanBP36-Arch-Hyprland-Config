# Arch Hyprland Configs

Centralized repository for my Arch Linux configuration files.

## 📦 What this installs
This setup automates the installation and symlinking of the following components:
- **Hyprland**: Window Manager
- **Waybar**: System status bar
- **Rofi**: Application launcher
- **Kitty**: Terminal emulator
- **Fastfetch**: System information display
- **Shell**: Configs for Zsh and Bash
- **Locking**: Hyprlock and custom lock menu

## 🚀 Quick Start
Use this single command to clone the repository and run the installation script on a fresh system:

```bash
git clone git@github.com:KeanBP36/KeanBP36-Arch-Hyprland-Config.git ~/dotfiles && cd ~/dotfiles && ./install.sh
