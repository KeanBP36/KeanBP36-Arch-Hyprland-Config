# My Arch Hyprland Configs

A centralized repository for my Arch Linux configuration files managed with symlinks.

## How to Install

If you are setting up a fresh Arch install, run the following commands:

```bash
# 1. Clone the repository
git clone git@github.com:KeanBP36/KeanBP36-Arch-Hyprland-Config.git ~/dotfiles

# 2. Run the installation script
cd ~/dotfiles
./install.sh
